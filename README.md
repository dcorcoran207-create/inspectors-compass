# Inspector's Compass
Static installable PWA. No framework, backend, Lovable or Base44 required.

## GitHub Pages
1. Create a GitHub repository named `inspectors-compass`.
2. Upload every file/folder in this package to the repository root.
3. Repository Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Open the Pages URL on Android Chrome → menu → Add to Home screen / Install app.

## Question bank
Edit `questions.js`. Each question has: id, topic, question, options, answer (zero-based option index), explanation, reference.

Progress and bookmarks are stored locally in the browser using localStorage.
